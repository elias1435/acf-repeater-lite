ACF Repeater Lite 1.0.1

Installation
Deactivate the previous plugin, then upload and activate this plugin. The folder and PHP entry point are now acf-repeater-lite.
For existing fields using the previous field type, select Repeater Lite again in ACF and save the field group. Keep the same field names and keys; stored row values are unchanged. Update any PHP/JSON field registrations to use type repeater_lite.

Requires Advanced Custom Fields. No site-specific branding is included.
